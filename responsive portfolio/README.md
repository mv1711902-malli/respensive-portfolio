# Advanced CSS3 & Responsive Architecture – Personal Portfolio Website

## 📌 Project Description
A modern and responsive Personal Portfolio Website developed using HTML5, CSS3, and JavaScript. This project demonstrates advanced CSS concepts, including CSS Grid, Flexbox, CSS Variables, Media Queries, and Dark/Light Mode.

## 🚀 Features
- Responsive Navigation Bar
- Modern Hero Section
- About Me Section
- Technical Skills Section
- Projects Showcase
- Contact Form
- Dark and Light Mode
- Mobile-Friendly Design
- Smooth Scrolling
- Interactive UI Elements

## 🛠️ Technologies Used
- HTML5 – Website Structure
- CSS3 – Styling and Responsive Design
- JavaScript – Interactive Functionality

## 📂 Project Structure
```text
Advanced-CSS3-Portfolio/
│
├── index.html

├── script.js
└── README.md
```

## 💻 How to Run the Project

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using the Live Server extension.
